# Java Bank CLI

A simple terminal-based banking system built in Java, focused on OOP.

## Features
- Create account
- List accounts
- Deposit
- Withdraw (with validations)
- Transfer between accounts

## Concepts used
OOP, ArrayList, encapsulation, validations, terminal menu.

## How to run
1. Compile:
```bash
javac src/*.java
```

2. Run:
```bash
java -cp src Main
```
